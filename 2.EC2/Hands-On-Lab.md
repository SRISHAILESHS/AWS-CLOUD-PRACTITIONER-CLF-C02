# EC2 Hands-On Lab

## Objective

Launch an EC2 instance using the AWS Management Console.

## Steps

1. Open AWS Management Console.
2. Search for EC2.
3. Open the EC2 Dashboard.
4. Select Launch Instance.
5. Enter an instance name.
6. Select an AMI.
7. Select an instance type.
8. Create/select a key pair.
9. Configure the security group.
10. Configure storage.
11. Launch the instance.
12. Check the instance state.
13. Connect to the instance.
14. Stop the instance.
15. Terminate the instance.
