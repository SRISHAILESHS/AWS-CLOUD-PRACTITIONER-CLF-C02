# AWS Database and Analytics — Real-World Use Cases

## 1. Amazon RDS
**Use case:** A college management system stores student details, fees, and attendance in a relational database.

**Why?** RDS manages database maintenance, backups, and other administrative tasks.

## 2. Amazon Aurora
**Use case:** An online shopping website needs a relational database for orders and payments with high performance and availability.

**Why?** Aurora is an AWS relational database engine designed for high performance and availability.

## 3. Amazon DynamoDB
**Use case:** A gaming application stores millions of player profiles and game scores.

**Why?** DynamoDB is a managed NoSQL database designed for fast, scalable key-value and document access.

## 4. Amazon ElastiCache
**Use case:** An e-commerce website frequently displays the same product details.

**Why?** It caches frequently accessed data in memory to reduce database queries and improve response time.

## 5. Amazon Redshift
**Use case:** A retail company analyzes five years of sales data to find its most profitable products.

**Why?** Redshift is a data warehouse designed for large-scale analytics and reporting.

## 6. Amazon EMR
**Use case:** A company processes billions of website click records to understand customer behaviour.

**Why?** EMR runs big-data frameworks such as Apache Spark and Hadoop to process large datasets.

## 7. Amazon Athena
**Use case:** A company stores sales reports as files in Amazon S3 and wants to calculate total sales using SQL.

**Why?** Athena queries data directly in S3 without requiring a database server.

## 8. AWS Glue
**Use case:** A company collects customer data from different systems and needs to clean and transform it before analysis.

**Why?** Glue is a managed data integration service used for discovering, preparing, and transforming data.

## 9. Amazon QuickSight
**Use case:** A manager wants a visual dashboard showing monthly revenue, profit, and sales trends.

**Why?** QuickSight is a business intelligence service used to create interactive dashboards and visualizations.

## Summary

- RDS → Relational databases
- Aurora → High-performance relational databases
- DynamoDB → NoSQL databases
- ElastiCache → In-memory caching
- Redshift → Data warehousing
- EMR → Big-data processing
- Athena → SQL queries on S3 data
- Glue → Data integration and transformation
- QuickSight → Dashboards and visual analytics
