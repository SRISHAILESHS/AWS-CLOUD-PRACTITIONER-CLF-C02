# AWS Compute Services — Hands-On Lab Ideas

## Lab 1: AWS Lambda

**Goal:** Create a simple Lambda function.

Steps:
1. Open the AWS Management Console.
2. Search for Lambda.
3. Choose Create function.
4. Select Author from scratch.
5. Enter a function name.
6. Choose a supported runtime.
7. Create the function.
8. Write a simple function that returns a greeting.
9. Deploy and test it.

Expected result: The function returns a response when successfully invoked.

## Lab 2: Amazon ECS

**Goal:** Explore ECS resources.

Steps:
1. Open the Amazon ECS console.
2. Explore clusters, task definitions, and services.
3. Learn the difference between a task and a service.
4. Review the Fargate and EC2 launch options.

Expected result: Understand how ECS organizes and runs containers.

## Lab 3: AWS Batch

**Goal:** Understand batch job configuration.

Steps:
1. Open the AWS Batch console.
2. Explore job queues and compute environments.
3. Review how job definitions specify the work to execute.
4. Learn how jobs are submitted and monitored.

Expected result: Understand the basic batch job workflow.

## Lab 4: Amazon Lightsail

**Goal:** Explore simplified cloud hosting.

Steps:
1. Open the Lightsail console.
2. Review available instance blueprints.
3. Explore instance plans and networking options.
4. Review how to connect to a virtual server.

Expected result: Understand how Lightsail simplifies hosting.

## Cost and Safety
- Review pricing before creating resources.
- Avoid launching paid resources unless you understand their costs.
- Delete test resources when finished.
- Confirm that no unwanted resources remain running.

Note: These are lab guides. Mark a lab as completed only after performing the steps in your AWS account.
