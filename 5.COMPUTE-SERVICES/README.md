# AWS Compute Services

## Introduction
AWS Compute Services provide the computing power required to run applications, execute code, process jobs, and host websites.

## Services Covered

### 1. Amazon ECS
Amazon Elastic Container Service (ECS) is a service used to run and manage applications inside containers.

**Example:** Running a billing application inside a container.

### 2. AWS Lambda
AWS Lambda runs code in response to events without requiring users to manage servers.

**Example:** Automatically resizing an image when it is uploaded to Amazon S3.

### 3. AWS Batch
AWS Batch helps schedule and run large numbers of batch computing jobs.

**Example:** Processing thousands of invoices automatically overnight.

### 4. Amazon Lightsail
Amazon Lightsail provides an easy way to launch and manage virtual servers, websites, and applications.

**Example:** Hosting a small business website.

## Quick Comparison

| Service | Main Purpose |
|---|---|
| ECS | Run containerized applications |
| Lambda | Execute code in response to events |
| Batch | Run batch computing jobs |
| Lightsail | Simple cloud hosting |

## Key Takeaway
ECS runs containers, Lambda executes event-driven code, Batch processes computing jobs, and Lightsail simplifies cloud hosting.
