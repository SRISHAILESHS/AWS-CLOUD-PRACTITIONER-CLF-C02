# AWS Compute Services — Interview Questions

## Amazon ECS

**1. What is Amazon ECS?**

Amazon ECS is a service for running and managing containerized applications.

**2. What is a container?**

A container packages an application with its required dependencies.

**3. What are the two common ECS compute options?**

Amazon EC2 and AWS Fargate.

## AWS Lambda

**4. What is AWS Lambda?**

Lambda runs code in response to events without requiring you to manage servers.

**5. What is a Lambda trigger?**

A trigger is an event or request that causes a Lambda function to run.

**6. Give one example of Lambda.**

Automatically processing an image uploaded to Amazon S3.

## AWS Batch

**7. What is AWS Batch?**

AWS Batch schedules and runs batch computing jobs.

**8. Give one use case for AWS Batch.**

Processing thousands of invoices or performing scientific calculations.

## Amazon Lightsail

**9. What is Amazon Lightsail?**

Lightsail is a simplified AWS service for launching virtual servers and hosting applications.

**10. When would you use Lightsail?**

When you want to host a small website without configuring many separate AWS services.

## Comparison Questions

**11. What is the difference between ECS and Lambda?**

ECS runs containerized applications, while Lambda executes code in response to events.

**12. What is the difference between AWS Batch and Lambda?**

Batch manages batch computing jobs, while Lambda runs individual function executions in response to triggers. Their capabilities and limits differ.

**13. What is the difference between EC2 and Lightsail?**

EC2 offers extensive configuration and control. Lightsail offers a simpler hosting experience with packaged pricing plans.
