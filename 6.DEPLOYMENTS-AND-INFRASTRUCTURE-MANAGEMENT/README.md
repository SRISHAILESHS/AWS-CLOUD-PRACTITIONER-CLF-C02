# Deployments and Managing Infrastructure at Scale

## Overview
This section covers AWS services used to automate infrastructure, deploy applications, build software, manage release pipelines, and operate AWS resources.

## Topics Covered
1. AWS CloudFormation
2. AWS Cloud Development Kit (CDK)
3. AWS Elastic Beanstalk
4. AWS CodeDeploy
5. AWS CodeCommit
6. AWS CodeBuild
7. AWS CodePipeline
8. AWS CodeArtifact
9. AWS Systems Manager (SSM)
10. SSM Session Manager
11. SSM Parameter Store

## Learning Objectives
- Understand Infrastructure as Code (IaC).
- Automate AWS infrastructure creation.
- Deploy applications using managed AWS services.
- Understand CI/CD workflows.
- Manage instances and application configuration.

## Folder Structure
- `Study-Resources/` - Notes, comparisons, use cases, and interview questions.
- `CloudFormation/` - CloudFormation notes, lab, and CLI commands.
- `Screenshots/` - Evidence from hands-on practice.
